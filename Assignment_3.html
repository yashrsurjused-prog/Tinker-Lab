Java

Java is a high level, object oriented programming language used to build platform independent applications.
It's "write once, run anywhere" features makes it one of the most widely used languages worldwide.

C++

A powerful extension of C that supports object - oriented programming.
Gives fine control over system resources & memory.

Kotlin

An modern, expressive language fully interoperable with Java, mainly used for Android development.
Reduces boilerplate code & improves safety with nullability handling

Java Script

The core scripting language for interactive web development
Supports both object oriented & functional programming paradigms

Rust

Systems programming language focused on safety, speed & concurrency.
Eliminates common bugs like null pointer dereferencing & data races at compile time

Go (golang)

Ideal for building scalable web servers, cloud services & network tools
Compiles to a single binary & has a fast compilation time
